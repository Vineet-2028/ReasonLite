# Separate native Halo smoke experiment
This is an **unexecuted** official Halo SFT/LoRA smoke recipe, not a fifth comparative checkpoint. Uses Qwen3-4B-Instruct-2507, the model in the official single-GPU LoRA example, and 32 deterministic ReasonLite SFT training records only. No validation/test data included. Two optimizer steps; no accuracy claims. Uses the documented Hopper image; requires a compatible H100/H200 host with R580+ driver and NVIDIA Container Toolkit. Do not pip-install Halo in Kaggle. Image tag and code commit are fixed; model revision is resolved and recorded on first execution. Image/source alignment and live training are not verified here. Run `bash run_halo.sh`; retain log, image metadata, model revision, adapter hash, trainer state and output. Review upstream license and data/model licenses before publishing. Docs: https://whitecircle.com/halo/docs/installation and https://github.com/whitecircle/halo/blob/3a21b4dbdb56cb840d42a59e98e40f967a1d2807/examples/sft/qwen3/qwen3-4b-ultrachat-lora.yaml
