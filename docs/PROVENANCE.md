# Evidence and release provenance

The principal source is the user-exported `ReasonLite_Notebook3_Complete.zip` (120 files). Additional earlier smoke evidence comes from Notebook 1 and the original/rescored baseline exports. The data manifest, scorer, final evaluator, original prediction files and saved adapters are kept byte-for-byte. The `runs/final_protocol_v1.json` lock identifies frozen source and checkpoint hashes. Earlier logs and reports are retained, including the nonfinite event. Generated reports are derived from predictions, not fabricated measurements.

Changes for this release: documentation, source organization, offline verification, CI, notebook review and a future GRPO log exporter fix. Exact executed GRPO source is archived at `provenance/train_grpo_executed.py`. The fix changes only the final log serialization, converting nonfinite log floats to null and recording original values in a sidecar; it does not change reward or optimizer settings. Existing recovery evidence is preserved. Historical notebooks are archival and may contain stale embedded source. The root Colab notebook is the original v0.1 artifact. Model binaries use safetensors; pickle `training_args.bin` files and optimizer checkpoint state are not distributed. Original completed run evidence is not a full replay of RNG/optimizer state.

`provenance/source_archives.json` records input archive hashes. `provenance/release_hashes.json` records distributed research source/evidence hashes. `scripts.audit_evidence` rechecks both lock and metrics without GPU; CI is added but must run remotely after push. Local offline checks are not a security audit or external reproducibility guarantee.

To check every original package byte, run `python -m scripts.audit_evidence --strict-release` before editing. The default audit checks frozen code/data/evidence only, so truthful changes to README or contribution documentation do not break CI. Preserve the original release hash manifest as historical provenance.
